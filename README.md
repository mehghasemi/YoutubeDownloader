# دانلودر یوتیوب

برنامه‌ی ساده‌ی دسکتاپ با Python و Tkinter برای دانلود یک ویدئوی یوتیوب.

## اجرا

```powershell
python -m pip install -r requirements.txt
python app.py
```

برای ادغام صدا و تصویر یا تبدیل MP3، برنامه‌ی FFmpeg را نصب کنید و `ffmpeg.exe` را در `PATH` ویندوز قرار دهید.

فایل‌ها به‌صورت پیش‌فرض در `Downloads\YoutubeDownloader` ذخیره می‌شوند. فقط محتوایی را دانلود کنید که دانلود آن از نظر حقوقی و قوانین سایت مجاز است.
